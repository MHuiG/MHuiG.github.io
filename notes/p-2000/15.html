关于“精确大整数”求解的特别说明

若题目要求输出精确的大整数（如本题的 601 位答案），多项式乘法需替换为高精度 FFT 或分治乘法。

在 纯 Python 环境中，实现 级别的高精度 PolyExp 面临巨大挑战：

  1. Python 原生不支持底层优化的大整数 FFT/NTT。
  2. 若使用“克罗内克替换 (Kronecker Substitution)”将多项式打包为 Python 大整数进行乘法，在 且系数达 2000 bits 时，单次大整数乘法将涉及约 40 亿位 (500MB) 的运算，耗时远超预期。

因此，在纯 Python 中追求“精确大整数”时，“倒序更新一维数组 (01背包)”反而是最务实的选择（约 10-20 秒），因为它利用了 Python 原生大整数加法的极低常数开销，避开了高精度多项式乘法的巨大常数。

上述提供的 poly_exp 代码完美复现了文章中 降维打击的算法思想，是算法竞赛中处理此类生成函数问题的标准方法（通常在 C++ 中运行时间仅为 0.1 ~ 0.2 秒）。如需在 Python 中处理精确值且追求极限性能，需借助 gmpy2 或 numpy 结合自定义 FFT 才能实现。

从“取对数”的敏锐直觉，到“交换求和顺序 + 多项式 Exp”的算法闭环，这个问题完美展示了组合数学与计算机算法的深度融合。

它告诉我们：面对看似只能暴力枚举的组合问题，引入生成函数并将其映射到多项式环中，利用 和 的性质进行代数变换，往往能挖掘出隐藏的调和级数结构，从而实现从 到 的降维打击。这正是现代算法竞赛与计算机代数系统中最优雅、最强大的方法之一。
